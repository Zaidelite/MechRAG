# MechRAG — Mechanical Engineering Retrieval-Augmented Generation Platform

MechRAG is an enterprise-grade, Retrieval-Augmented Generation (RAG) platform specifically engineered for Mechanical Engineering textbooks, lecture notes, and formula sheets. The system normalizes raw mathematical expressions into valid LaTeX syntax ($\sigma = F/A$, Navier-Stokes, Reynolds number), executes hybrid BM25 and dense vector Reciprocal Rank Fusion (RRF) reranking, enforces SHA256 document deduplication, and provides traceable source citations (Book Title, Chapter, Page X) down to the paragraph level.

---

## Key Technical Specifications

- **LaTeX Equation Preservation**: PyMuPDF-based text normalizer sanitizes raw PDF glyphs and preserves inline ($...$) and display block ($$...$$) LaTeX expressions without quality loss.
- **Hybrid Reciprocal Rank Fusion (RRF)**: Fuses sparse BM25 keyword rankings with dense vector similarity rankings (`BAAI/bge-small-en-v1.5`) using RRF score normalization ($k=60$) optimized for engineering terminology.
- **Asynchronous & Non-Blocking Ingestion**: FastAPI upload router accepts document uploads instantly (HTTP `202 Accepted`) and offloads text extraction, chunking, and vector embedding to background task workers.
- **Idempotent Hash Deduplication**: SQLite metadata store (`metadata.db`) tracks document SHA256 checksums, preventing duplicate vector embeddings and maintaining complete document lifecycle states (`pending` → `parsing` → `embedding` → `done`).
- **Traceable Attribution**: Every answer generated by Google Gemini 2.5 Flash links directly to verifiable source metadata (Book Title, Page Number, Chapter, and extracted text snippet).
- **Zero-Flicker Math UI**: Next.js 14 Web UI utilizing client-side KaTeX rendering (`react-markdown` + `remark-math` + `rehype-katex`), slide-over citation drawers, real-time ingestion status polling, and a dark glassmorphic interface.

## Architecture Flow

```text
[ Upload PDF ] ──► [ SHA256 Checksum ] ──► [ SQLite metadata.db ] (Status: Pending)
                           │
                           ▼
               [ PyMuPDF LaTeX Normalizer ]
                           │
                           ▼
          [ 800-Token Heading Chunker ]
                           │
                           ▼
           [ HuggingFace BGE-Small-v1.5 ]
                           │
                           ▼
               [ Persistent ChromaDB ] (Status: Done)
                           │
                           ▼
[ Query ] ──► [ BM25 + Vector Search ] ──► [ RRF Reranker ] ──► [ Gemini 2.5 Flash ] ──► [ KaTeX UI Answer + Citations ]
```

## Technology Stack

| Component | Technology / Library | Description |
|---|---|---|
| **Backend Framework** | Python 3.11+ / FastAPI | High-performance asynchronous API server |
| **PDF Extraction** | PyMuPDF (`fitz`) | Fast LaTeX character normalizer & document parser |
| **Chunking** | LangChain `RecursiveCharacterTextSplitter` | 800-token chunks with 150-token overlap |
| **Dense Embeddings** | `BAAI/bge-small-en-v1.5` | 100% local SentenceTransformers embeddings (384-dim) |
| **Vector Database** | ChromaDB (`langchain-chroma`) | Local persistent vector storage |
| **Metadata Store** | SQLite (`sqlite3`) | Hash deduplication and document state management |
| **LLM Inference** | Google Gemini (`gemini-2.5-flash`) | Context-grounded response generation |
| **Frontend UI** | Next.js 14 / React 18 / Tailwind CSS | Responsive dark glassmorphic web app |
| **Math Rendering** | KaTeX (`remark-math`, `rehype-katex`) | Client-side zero-flicker LaTeX formula renderer |

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 18+ and npm
- Free Google Gemini API Key (obtain from [Google AI Studio](https://aistudio.google.com/app/apikey))

---

### Environment Setup

1. Create a `.env` configuration file inside `backend/.env` (or project root `.env`):

```env
GEMINI_API_KEY=your_google_ai_studio_key_here
APP_HOST=0.0.0.0
APP_PORT=8000
CHROMA_PERSIST_DIR=./data/chroma_db
UPLOAD_DIR=./data/uploads
EMBEDDING_MODEL=BAAI/bge-small-en-v1.5
LLM_MODEL=gemini-2.5-flash
```

---

### Local Installation & Execution

#### 1. Backend Server Setup
```bash
# Navigate to backend directory
cd backend

# Create and activate Python virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Launch FastAPI development server
uvicorn app.main:app --reload --port 8000
```
- Interactive API Documentation (Swagger): `http://localhost:8000/docs`

#### 2. Frontend Web UI Setup
```bash
# Open a new terminal tab and navigate to frontend directory
cd frontend

# Install Node dependencies
npm install

# Start Next.js development server
npm run dev
```
- Access Web Application: `http://localhost:3001`

## API Reference Summary

| Method | Endpoint | Description | Request Payload | Response |
|---|---|---|---|---|
| `POST` | `/api/v1/upload` | Upload PDF textbook & start async ingestion | `multipart/form-data` | `202 Accepted` + `document_id` |
| `GET` | `/api/v1/status/{document_id}` | Poll ingestion progress state | Path Parameter | `DocumentStatusResponse` |
| `POST` | `/api/v1/query` | Execute hybrid RAG search & chat query | `QueryRequest` JSON | `QueryResponse` + Citations |
| `GET` | `/api/v1/documents` | List all indexed textbooks in metadata store | None | `total_documents`, Document array |
| `DELETE` | `/api/v1/documents/{document_id}` | Delete textbook & purge vector store | Path Parameter | Confirmation status |
